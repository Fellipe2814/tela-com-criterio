# Tela com Critério

Uma página de vendas para o guia **"Tela com Critério"** — um material informativo sobre desenhos educativos para bebês de 0 a 3 anos.

## 📋 O que é?

Um guia prático com 15 páginas que ajuda pais a reconhecer, em segundos, quais desenhos ajudam o desenvolvimento do seu filho e quais só prendem a atenção.

### Conteúdo:
- ✅ Checklist do bom desenho
- ✅ Comparativo educativo vs. prendedor de atenção
- ✅ 8 desenhos recomendados
- ✅ Análise de Cocomelon, Baby Shark e Peppa Pig
- ✅ Recomendações de tempo de tela
- ✅ Checklist para imprimir

## 📝 Customizações

Para editar o conteúdo, basta modificar o arquivo `index.html`.

### Alterar o link de checkout:
Encontre a linha no script:
```javascript
const CHECKOUT_URL = "https://pay.kiwify.com.br/eHMLA7F";
```

E substitua pela sua URL de checkout da Kiwify.
